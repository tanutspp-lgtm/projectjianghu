V187.1 HOTFIX — ใช้ทับ V187 (ไม่ใช่ไฟล์เต็ม)

รายการแก้
1. แก้สกิลขึ้นนอกระยะทั้งหมดหลังเล่นไปสักพัก: มอนทั่วไปไม่กลายเป็นเป้าล็อกอัตโนมัติ แยกเป้าที่ผู้เล่นล็อกเองออกจากผู้โจมตีล่าสุด การโจมตีตามทิศไม่ติดเงื่อนไขระยะของเป้าอัตโนมัติที่ไกลออกไป เป้าที่ล็อกเองยังตรวจระยะจริง และปุ่มเลือกเป้ามีจังหวะปลดล็อก
2. เปลี่ยนตำแหน่ง wheel แล้วใช้ผังใหม่ได้ทันที ปล่อย pointer/ปุ่มค้าง ไม่ล้างคูลดาวน์ เรจ หรือ CC
3. แก้สถานะออนไลน์เก่าล้างตัวละครเมื่อเข้าสนามซ้อม PvP และป้องกันงานโหลดเก่าย้อนมาทับสนามใหม่
4. บล็อกสำเร็จขึ้น BLOCK และเสียงโลหะ ไม่เล่นเสียงโดนเนื้อซ้ำ กรณีเจาะการ์ดสำเร็จไม่นับเป็นบล็อก
5. ลบหลอดเรจและการ์ดที่วางค้างบน HUD อันติแสดง % บนปุ่ม รวม 100% และมีออร่าทองเมื่อเต็ม คูลดาวน์อันติจริงยังแสดงเลขวินาทีเล็กด้านล่างเมื่อมี
6. การ์ดแสดงหลอดสีเทาเหนือหัวหลังบล็อกสำเร็จ 1.8 วินาที และค่อยจาง ไม่แสดงค้างตอนยังไม่ถูกตี
7. อันติทุกคลาสติดตัวทองตลอดช่วงออกท่า รับดาเมจได้ แต่ไม่ติด hit lock/ล้ม/แรงผลัก สตันและหลับยังหยุดได้ และเมื่อถูกขัดด้วยสถานะเหล่านี้แสงทองจะจบ สามารถออกจากล้มด้วยอันติได้เมื่อเรจพร้อม แต่ใช้ฝ่าสตัน/หลับไม่ได้

ASPD ยังไม่รวมในรอบนี้ ตามคำสั่งหยุดเพิ่มระบบเพื่อส่งแพตช์แก้บั๊กก่อน ค่าความเร็วและคูลดาวน์โจมตีธรรมดายังคง V187

ติดตั้ง Frontend
แตก JIANGHU_FRONTEND_V187_1_PATCH_FROM_V187.zip ทับโฟลเดอร์ Frontend V187 เดิมที่มี index.html และ assets อยู่แล้ว แล้ว deploy โฟลเดอร์เกมที่รวมแล้วทั้งหมด ห้ามอัป ZIP แพตช์นี้เป็นเว็บไซต์เดี่ยว เพราะไม่ได้ใส่ภาพ/เสียงเก่าและไฟล์เดิมทั้งหมด
คีย์บอร์ด ผังสกิลที่บันทึก และค่าตั้งเดิมยังอยู่ หลังอัปสำเร็จปิดเปิดหรือรีเฟรชเว็บหนึ่งครั้งเพื่อโหลดโค้ดแพตช์ (หลังจากนั้นการย้ายสกิลไม่ต้องรีเฟรช)

ติดตั้ง Backend — จำเป็นสำหรับแก้นอกระยะออนไลน์
แตก JIANGHU_BACKEND_V187_1_DELTA_FROM_V187.zip ทับ Backend V187 เดิม ภายในโฟลเดอร์ที่มี server.py แล้วรัน:
bash RESTART_AND_VERIFY_V187_1.sh
สคริปต์ตรวจหาเฉพาะ service เดิมที่ WorkingDirectory ตรงกับโฟลเดอร์นี้และรัน server.py ถ้าพบไม่ใช่หนึ่งตัวจะหยุด ไม่สร้างหรือเปลี่ยน service อื่น
healthz ต้องมี JIANGHU_BACKEND_V187_1 และ martial-lock-state-v1871-v1 การคัดลอกไฟล์อย่างเดียวไม่เปลี่ยน process ที่กำลังรัน ต้อง restart ด้วย
ถ้าใช้ Git ต้องนำไฟล์แพตช์เข้า repository ของคุณและ push ก่อน git pull จะดึงได้ แพตช์นี้ไม่ได้ถูก push/deploy หรือ restart VPS ให้โดยอัตโนมัติ
หากเครื่องยังเป็น Backend181 ต้องลง delta187จาก181 ที่เคยส่งก่อน แล้วค่อยลง187.1 ห้ามใช้deltaจาก187ทับ181ตรงๆ

ขอบเขตตรวจสอบ
ทดสอบโค้ด combat JS/Python, การสลับผัง 480 แบบ x2หน้า ด้วย click/pointer/keyboard 17,280 คำสั่ง, วงจร online→arena→offline, guard/audio/เกจชั่วคราวและตัวทอง รวม socket จริงของ backend ท้องถิ่น ตรวจทิศเอฟเฟกต์เดิม 1,536 กรณี
ในเบราว์เซอร์ทดสอบบันทึกผังแล้วร่ายได้โดยไม่รีเฟรช และเข้า arena เห็นตัวละครจริง รายงานละเอียดอยู่ QA_V187_1.json
ยังไม่ได้ทดสอบบน VPS ของคุณหรืออุปกรณ์ iOS/Android จริง ไม่มีการเปลี่ยน world geometry, ภาพตัวละคร, สูตรดาเมจ, หลักฮีล40%/60วินาที หรือทิศเอฟเฟกต์ที่อนุมัติไว้
