ใช้ไฟล์นี้ลงทับ Backend V181 FULL ได้โดยตรงเพียงครั้งเดียว
รวม Backend V182+V183+V184 แล้ว ไม่ต้องลงแพทช์กลาง ไม่ใช่ Backend ตัวเต็ม
Frontend ใช้ V184 FULL 3 พาร์ตที่ส่งแยกไว้พร้อม MERGE_V184.ps1

สิ่งที่รวมอยู่ฝั่ง Backend:
- ออนไลน์ประกาศ feature/version ให้ Frontend ตรวจคู่รุ่น พร้อมแสดงข้อผิดพลาดแทนค้างโหลด
- กระบี่/สกุลถังสลับฟัน1–2 ระยะ134/102และทิศฟันจากเซิร์ฟเวอร์
- ส่งข้อมูล profession/shotDir ให้เอฟเฟกต์ออนไลน์ตรงชนิดอาวุธ
- Aim Assist เป็นตัวเลือก defaultOFF; หันหน้าทางไหนโจมตีทางนั้น; AUTOยังใช้เป้าของตน
- สกุลถังโจมตีธรรมดาเลือกฟันในระยะหรือปามีดนอกระยะ ไม่กินลำดับฟันเมื่อปา
- หมอฮีลคูลดาวน์3วินาทีแยกจากพักอนิเมชั่น.60วินาที แล้วตีธรรมดาต่อได้
- แรงผลักระยะประชิดไม่เด้งมอนข้ามหลังผู้โจมตี
- ทั้ง4อาชีพตรวจความสูงจริง/พื้นและผนังคั่น ไม่ตีหรือทำสถานะข้ามชั้น
- ปราณสะท้อนไม่ลัดผ่านพื้นไปอีกชั้น และกระสุนหยุดเมื่อชนฉาก

งานภาพ/ขนาดตัวละคร/เอฟเฟกต์/แมพหิมะ-ท่าเรืออยู่ใน Frontend V184 FULL
Backendอย่างเดียวไม่เปลี่ยนภาพของFrontendเก่า

ติดตั้ง:
1. แตก ZIP นี้แล้วคัดลอกไฟล์ทั้งหมดทับโฟลเดอร์ Backend V181 เดิม
   หากใช้Git ให้commit/pushไฟล์เหล่านี้เข้าrepoเดิมก่อน; git pullไม่อัปไฟล์ที่ยังไม่ได้push
2. บนVPSในโฟลเดอร์repoBackend:
   git pull --ff-only
   bash RESTART_AND_VERIFY_V184.sh
   หากคัดลอกไฟล์ลงVPSโดยตรง ไม่ต้องgit pullซ้ำทับไฟล์ที่เพิ่งคัดลอก
3. ต้องเห็น /healthz รายงาน JIANGHU_BACKEND_V184 และ combat-layers-v184-v1
   ตรวจอย่างเดียวได้ด้วย python3 VERIFY_RUNNING_V184.py

สคริปต์หาserviceเดิมจากWorkingDirectory+server.py และตรวจไฟล์ก่อนrestart
ถ้าพบserviceไม่ตรงเพียง1รายการจะหยุด ไม่สร้างserviceใหม่
แพทช์นี้ไม่มี.env/.venv/ฐานข้อมูล/service config และไม่ต้องลบไฟล์V181ใดๆ
ไฟล์README_V182/183เป็นประวัติเดิม ให้ยึดไฟล์คำแนะนำนี้สำหรับการติดตั้งจาก181
ยังไม่ได้push/restartVPSจริงจากแชทนี้
