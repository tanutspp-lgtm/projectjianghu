WUXIA FLUTE ARENA v7.8 WEB — FOUR-TAB / AFK STABILITY

ปรับจาก v7.7 เดิม:
- ส่ง input ผ่าน timer แยกจาก requestAnimationFrame (เมื่อ FPS ต่ำหรือแท็บถูกซ่อน การส่ง input ไม่ยึดกับเฟรมภาพ)
- เมื่อเบราว์เซอร์ซ่อนแท็บ / blur จะหยุดการเดิน/ค้างปุ่ม และถ้า timer ทำงานจะส่งปุ่มว่างเป็นระยะ
- ถ้า WebSocket หลุดโดยไม่ใช่การกดออกเอง จะขึ้น "กำลังต่อกลับ..." และลองใหม่โดยเว้นช่วง
- เมื่อกลับมาที่แท็บหรืออินเทอร์เน็ตกลับมา จะลองต่อใหม่ทันที
- เก็บ resume token แบบชั่วคราวใน sessionStorage ของแต่ละแท็บ (ไม่ใช่ localStorage รวม 4 แท็บ)
- หากเน็ตขาดหรือแท็บถูก OS พัก จะขอกลับเข้าตัวละครเดิมภายใน 5 นาทีเมื่อเซิร์ฟเวอร์ยังมี session
- รักษาตัวละคร 30 ชีท, การสร้างตัวละคร, การ์ด, แดช, ปีน, สกิล, เอฟเฟกต์, มอนสเตอร์ และตัวเลข FPS เดิม
- เว็บยังส่งเฉพาะปุ่มกด ไม่ส่ง HP / x-y / Damage / ค่ามอนสเตอร์ให้เซิร์ฟเวอร์ตัดสิน

วิธีใช้: อัปเดต server.py บน GitHub/Render Singapore ให้เป็น v7.8 ก่อน แล้วจึงอัปเดต ZIP เว็บนี้บน Netlify

คำเตือน: Safari/iPad อาจพัก/ปิดแท็บที่ไม่ใช้งานจน WebSocket หลุด แม้จะไม่มีบั๊กเกม ระบบจะพยายามเชื่อมใหม่เมื่อเปิดแท็บ และรักษาสถานะเดิมได้เฉพาะภายใน 5 นาทีและถ้า server process ไม่รีสตาร์ต
