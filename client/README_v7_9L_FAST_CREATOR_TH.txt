WUXIA FLUTE ARENA v7.9L - Fast Character Creator (web-only)

ต่อยอดจากไฟล์ v7.9K (แก้เดินผ่านบันได) โดยไม่เปลี่ยน physics, server หรือ Sprite 24 เฟรมเดิม

- เพิ่ม character_previews/*.webp จำนวน 30 ไฟล์ จาก IDLE Frame 0 และ 1 ของ Sprite Sheet ต้นฉบับ
- หน้าเลือกตัวละครโหลดแค่ภาพ Preview 512x256 แทน Atlas เต็ม 1536x1024
- ตอนเริ่มออฟไลน์หรือออนไลน์ค่อยโหลด Atlas เต็มของตัวละครที่เลือก
- ระหว่างหน้าสร้างตัวละครยังไม่โหลดภาพพื้น เอฟเฟกต์ มอน และ background; โหลดตอนเริ่มเล่น
- Peer sprites ออนไลน์ยังโหลดตามที่เห็นผู้เล่น และคงระบบเดิมทั้งหมด
- ยังคงไฟล์ characters/*.png ครบทั้ง 30 แบบ ไม่มีการแก้ภาพต้นฉบับ
- ไม่แตะ Game Server / ยังไม่ Deploy

ตรวจผลก่อนเผยแพร่: สร้างตัวละคร เปลี่ยนทั้ง 2 เพศ / 3 ทรง / 5 สี, เริ่มออฟไลน์, เข้าออนไลน์, เปลี่ยนตัวละครหลังเข้าเกม, network caching.
