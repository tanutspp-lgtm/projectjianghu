WUXIA FLUTE ARENA v7.9 — Joystick + Right Jump + AUTO (เว็บเกม)
ฐาน: v7.8 GUEST ONLINE WEB AFK RECONNECT

เพิ่ม:
- จอยอนาล็อกวงกลมมุมซ้ายล่าง เลื่อนนิ้วซ้าย-ขวาเพื่อเดิน/หันหน้า ขึ้น-ลงสำหรับปีนเชือกหรือบันได
- ปุ่มกระโดดย้ายไปอยู่ในกลุ่มสกิลมุมขวาล่าง
- ปุ่ม AUTO ON/OFF อยู่ฝั่งขวา และปุ่ม P บนคีย์บอร์ด
- AUTO ออฟไลน์ไล่มอนสเตอร์บนชั้นเดียวกัน ระยะไม่เกิน 720 และใช้ดาเมจ/คูลดาวน์ตามเกมเดิม
- AUTO ออนไลน์ส่งเพียงคำสั่งเปิด/ปิด Server Authoritative ให้เซิร์ฟเวอร์คุม AI เอง ไม่ส่งดาเมจหรือพิกัด
- พอผู้เล่นกดจอย/สกิลเอง จะยกเลิก AUTO

ความเข้ากันได้:
- ใช้เว็บ v7.9 กับเซิร์ฟเวอร์ v7.8 หรือเก่ากว่าได้สำหรับการเล่นออนไลน์ธรรมดา
- AUTO ออนไลน์ต้องอัปเดตเซิร์ฟเวอร์ v7.9 ก่อน: ไคลเอนต์จะไม่ส่งแพ็กเก็ตใหม่ให้เซิร์ฟเวอร์เก่า
- ไม่ต้องอัปเดต Render ตอนนี้ ถ้าต้องการเก็บไปอัปเดตพร้อมกันทีหลัง
- อย่าอัปเดตเว็บและทดลอง AUTO ออนไลน์กับ server เก่าแล้วคิดว่าเกมพัง: จะขึ้นแจ้งเตือนให้อัปเดต Server

ขอบเขต AUTO รุ่นแรก:
- ไล่มอนที่มีชีวิตและอยู่บนแพลตฟอร์มเดียวกัน ไม่ปีนอัตโนมัติ ไม่สลับชั้นหรือแผนที่
- ไม่ดูดมอน ไม่วาร์ป ไม่ตี PvP อัตโนมัติ ไม่คืน HP ฟรี ไม่ใช้บัฟโกง
- ถ้าผู้เล่นโดนตีล้ม/ตาย AUTO รอให้พ้นสถานะก่อน (ถ้าเซิร์ฟเวอร์ยังเชื่อมต่อ)
- หาก Safari พัก/ปิด WebSocket จริง จะใช้ระบบต่อกลับ v7.8 เมื่อแท็บตื่น; ไม่สามารถฝืนให้แท็บไม่ถูกพักโดยระบบปฏิบัติการ

การทดสอบ:
- UI จำลอง 844x390: จอยคืนศูนย์ ปุ่ม AUTO ทำงาน ไม่พบ JavaScript error
- โหมดเซิร์ฟเวอร์: test_auto_mode.py, test_auto_unit.py, test_security.py ผ่าน
- ตรวจ SHA-256 ของรูปตัวละคร เฟรม เอฟเฟกต์ รวม 85 ไฟล์: ตรง v7.8 ทุกไฟล์
- ยังไม่ได้ทดสอบ Safari iPad เครื่องจริง
