PROJECT JIANGHU — FRONTEND V66 / BACKEND WORLD V17

แก้จาก V65
1. ถอดภาพปากถ้ำที่ดูเป็นก้อนหินแปะทับออกจากการวาด
   แก้ช่องถ้ำลงบนส่วนผิวหินต้นฉบับจริงในกรอบ Source [896,420,512,512]
   ผสมขอบส่วนแก้กับภาพเดิมครั้งเดียวแล้ว Cache ไม่ทำใหม่ทุกเฟรม
   เก็บภาพคู่หน้าผาต้นฉบับไว้เหมือนเดิม ไม่เปลี่ยนภาพฝั่งด้านหน้า
   ช่องสูงประมาณตัวละคร ยึดตำแหน่งโลก ไม่เลื่อนกับวิวไกล
2. เพิ่มวาร์ปที่แมพ 28 หน้าปากถ้ำ [1360,-4250]
   ยืนบนแพลตฟอร์มตรงปากถ้ำแล้วกดขึ้น เพื่อเข้าถ้ำเซียนกระบี่ชั้นบน
   เข้าไปเกิด [2180,-140] ฝั่งขวาของถ้ำ
   ทางเดินออกถ้ำกลับมายังผายังใช้ทางเดิม เปลี่ยนจุดเกิดเป็น [1240,-4250]
   ให้ห่างจากวาร์ป เพื่อไม่ให้วนกลับทันที
3. ตรวจตำแหน่ง ระดับพื้น สถานะยืน และการกดขึ้นที่ Backend
   ไม่รับพิกัดวาร์ปจาก Client ตามใจ

ชุดนี้รวมตัวแก้ V65 เดิมทั้งหมด: ถ้ำเดินแล้วเด้งกลับ, บันไดแมพ 28 ขึ้น/ลง,
หน้าผา/วิวฝั่งป่า, HUD HP/SP/STA/EXP, ใบไม้ซ้ายบนแมพ 30–34
ไม่เปลี่ยนพื้น/แพลตฟอร์ม/บันได/เชือก Collision หรือ Netcode จาก V65
Self 30Hz / AUTO และระบบต่อสู้/ไอเทมเดิมคงเดิม

Frontend: JIANGHU_FRONTEND_V66_FULL.zip เป็นตัวเต็มไฟล์เดียว
แตก ZIP แล้วอัปทั้งโฟลเดอร์เข้า Vercel ตามเดิม มี index.html ที่ Root
ไม่ต้องใช้ GitHub สำหรับ Frontend และไม่ต้องรวมพาร์ทเอง

Backend: JIANGHU_BACKEND_V66_FULL.zip เป็นตัวเต็ม มี server.py ที่ Root
อัปไฟล์ใน ZIP ผ่าน GitHub เข้า repo เดิม และ Commit ตามเดิม
server.py ตรงกับ GitHub ที่ตรวจ ณ รอบนี้; ไฟล์การทำงานที่เปลี่ยนรอบ V66 คือ world_v56.json
มี CHECK_WORLD_V66.py ให้ตรวจหลัง pull
ต้องอัป Frontend และ Backend ชุด V66 ให้ตรงกัน เพราะเพิ่มเส้นทางวาร์ป
ไม่แตะ .env / .venv / systemd drop-in

เมื่ออัป Backend ผ่าน GitHub แล้ว รันบนเครื่องเซิร์ฟเวอร์:
cd /opt/jianghu || exit
tar -czf "/opt/jianghu-backup-$(date +%Y%m%d-%H%M%S).tar.gz" --exclude=.git --exclude=.venv --exclude=__pycache__ -C /opt jianghu &&
git pull --ff-only &&
.venv/bin/python CHECK_BEFORE_RESTART.py &&
.venv/bin/python CHECK_WORLD_V66.py &&
systemctl restart jianghu.service &&
systemctl status jianghu.service --no-pager -l

ผลตรวจ
- เล่นผ่านเบราว์เซอร์กับ WebSocket/เกมลูป Backend ในเครื่องทดสอบ
  ใช้พิกัดเริ่มต้นที่ตั้งฝั่งเซิร์ฟเวอร์หนึ่งครั้ง แล้วกดปุ่มจริงเดินเข้า/ออก 3 รอบ
  วาร์ปผ่านการตรวจฝั่งเซิร์ฟเวอร์ครบ 6 ครั้ง ไม่เด้งวนกลับ และไม่พบ JS error/ไฟล์โหลดหาย
- Backend ปฏิเสธการเข้าถ้ำเมื่อไม่กดขึ้น, อยู่ไกล, ผิดชั้น, ลอยตัว หรือกำลังปีน
- Geometry เล่นได้ทุกแมพและฟิสิกส์จาก V65 ไม่เปลี่ยน; FE/BE JSON ตรงกัน
- ไม่มีไฟล์จากชุดเต็ม V65 ถูกตัดออก
- ตรวจ Syntax และ ZIP CRC/root entry ก่อนส่ง
ไม่ได้ Deploy หรือทดสอบบน Vercel/Hostatom ที่คุณใช้งานจริง
เอกสาร V65 ที่เก็บอยู่เป็นประวัติ ให้ยึด README_V66_TH.txt สำหรับชุดนี้
