Project Jianghu — Frontend / Backend V181
9 พฤศจิกายน 2026 (ประเทศไทย)

ใช้คู่กัน: Frontend V181 + Backend V181 (World V52 เดิม)
รอบนี้ต้องอัป Backend ด้วย เพราะรับตัวละคร 8 แบบใหม่ จังหวะปล่อยอาวุธ ระยะฟัน และเข็มรักษา
ยังไม่ได้อัปโหลดหรือ Restart VPS จริงให้ผู้ใช้

ตัวละคร
- กระบี่ / ขลุ่ย / สกุลถัง / หมอ ครบชาย–หญิง รวม 8 ตัว 288 เฟรม
- ใช้ชีตที่อนุมัติในแชต ตัดพื้นหลังออกและแพ็กเป็น WebP alpha
- 36 ช่อง/ตัว: idle+กะพริบตา4, เดิน8, กระโดด4, แดช2, ปีน2, เจ็บ/กระเด็น/ล้ม/ตาย4, ท่าหลัก6, ท่าที่สอง6
- ขนาดภาพยืนใกล้ตัวขลุ่ยเดิม หัวและตัวใช้สเกลเดียวกันตลอดแต่ละชุด วัดจุดเท้าคงที่แยกตามชีตและคง grounded +7 เดิม ไม่ยืดตัวแยกจากหัว
- อาชีพหมอใช้ชุดเทา หมวกยอดพับขนาดเล็ก ไม่มีเม็ดกลม ตามเวอร์ชันล่าสุด
- ลบภาพตัวละครขลุ่ยเก่า: characters/, character_previews/, frames/ และ player_reference เก่า
- เลือกอาชีพและเพศในหน้าสร้างตัวละคร แทนตัวเลือกทรง/สีผมที่ไม่มีภาพรองรับแล้ว

ปุ่มต่อสู้
- J กระบี่: ฟันระยะใกล้ / K: กระบี่กวาด / U: ทลายการ์ด
- J สกุลถัง: ฟันมีดระยะใกล้ / K: ปามีด / U: มีดทลายการ์ด
- J หมอ: ปาเข็ม / K: เข็มรักษา / U: เข็มทลายการ์ด
- หมอ K ใช้ SP16 คูลดาวน์3วินาที รักษา15%MaxHP ของเป้าหมาย ไม่เกินเลือดเต็ม
  ออนไลน์เลือกตัวเองหรือเพื่อนที่ HP เป็นสัดส่วนต่ำที่สุดในระยะ300และระดับความสูงใกล้กัน
  เฉพาะโลก/แผนที่/CH เดียวกัน ออฟไลน์รักษาตนเอง ไม่มีการรักษามอนสเตอร์
- ขลุ่ย: คง J/K/U เดิม ใช้ท่าเป่าสองจังหวะและคลื่นพลังใหม่
- สกิล U ของแต่ละอาชีพใช้หนึ่งในสองท่าที่มีอยู่ ไม่ประดิษฐ์ท่าที่สาม
- การเติบโต สเตตัส ปราณ และสูตรดาเมจเดิมยังเป็นฐานร่วม ไม่ใช่ชุดบาลานซ์อาชีพปลายทางใหม่

เอฟเฟกต์/เสียง
- ภาพเอฟเฟกต์เจนเป็นภาพจริง 6ชุด x 8เฟรม: แสงกระบี่ แสงมีด มีดบิน เข็มบิน คลื่นขลุ่ย แสงรักษา
- อาวุธออกในจังหวะปล่อยกลางท่า ไม่พุ่งออกก่อนมือขยับ
- ท่าถูกขัดด้วยตาย/ล้ม/สตัน/ปีน/การ์ดก่อนปล่อย จะไม่สร้างกระสุนหรือรักษาฟรี
- เอฟเฟกต์ออนไลน์อิง cast/release ที่เซิร์ฟเวอร์ยอมรับ ไม่ให้ Client ตัดสิน HP หรือดาเมจ
- เสียงขลุ่ย กระโดด โดนตี เก็บของ เสียงมอนตาย และ BGM เดิมคงไฟล์เดิม
- เพิ่มเสียงสั้นสำหรับฟัน/ปามีด/ปาเข็ม/รักษา แยกอาชีพ ไม่เปิดเสียงขลุ่ยให้กระบี่ มีด หรือหมอ

ประสิทธิภาพ
- 1 atlas/ตัว 1152x1152 RGBA (192px x 36ช่อง) ไม่เก็บ GIF เป็นตัวเดินในเกม
- โหลดแค่ตัวอย่างขนาดเล็ก8แบบ และโหลด atlas ตัวที่เลือกก่อนเข้าเล่น
- เอฟเฟกต์โหลด/ถอดรหัสครั้งเดียว ใช้ซ้ำ ไม่มีสร้างภาพ/ตัดภาพระหว่างโจมตี
- รักษา self30Hz, world/others10Hz, authoritative server และกฎไม่มี PvP เดิม
- World V52, พื้น/แมพ/วาร์ป/physics, V180 HUD/มือถือ/มินิแมพ/แชต และแก้ถ้ำเดิมไม่ได้เปลี่ยน

ติดตั้ง
1. ดาวน์โหลด FULL_PART_1/2/3, BACKEND_V181_FULL.zip และ MERGE_V181.ps1 ไว้โฟลเดอร์เดียวกัน
2. เปิด PowerShell แล้วรัน MERGE_V181.ps1 ตามคำสั่งที่ส่งในแชต
3. สคริปต์ตรวจ SHA256 แล้วแตกทั้งสาม ZIP ลง frontend โฟลเดอร์ใหม่แยกจาก backend
   ใช้โฟลเดอร์ใหม่เพื่อไม่เหลือภาพขลุ่ยเก่าค้างจากการทับไฟล์
4. อัปโหลดเนื้อหาโฟลเดอร์ frontend ขึ้นเว็บตามวิธีเดิม
5. อัปโหลด Backend V181 ให้ครบ โดยเฉพาะ server.py, character_classes_v181.py, farm_auto_v80bu.py
   ใช้ environment/config ของเซิร์ฟเวอร์เดิม แล้ว Restart ตามวิธีเดิม

ขอบเขตการตรวจ
- ตรวจทั้ง8ตัว: ภาพ alpha/ขนาด/36ช่องไม่ว่าง, เอฟเฟกต์48เฟรมถอดรหัสได้
- เรียก fireSkill/updateProjectiles จาก source จริงครบ24เส้นทาง (8ตัว x J/K/U)
- ตรวจทุกเฟรม0..35เข้าถึงได้จริง, config JS/Python ตรงกัน
- ตรวจระยะฟัน ไม่โดนตัวด้านหลัง/ไกล, windup/ขัดท่า, heal/SP/cooldown/เลือดเต็ม และ wire schema
- ต่อ WebSocket เซิร์ฟเวอร์ทดสอบจริงครบ8ตัว พบ cast และ release ทั้งหมด
- regression ไม่มี PvP, ปราณเดิม และ cast metadata ผ่าน
- เปิดเกมจริงใน browser: creator, ตัวกระบี่, หมอหญิง และตรวจ renderer art/FXครบ8ตัวในหน้าทดสอบแยก
- Cloud browser render ช้ามาก ไม่ใช้ตัวเลข FPS ของเครื่องนี้อ้างประสิทธิภาพบน iPad/iPhone/PC
- ยังไม่ได้ทดสอบอุปกรณ์จริง/เซิร์ฟเวอร์ VPS จริง หน้า QA และ config preview ไม่รวมในเกมที่ส่ง
