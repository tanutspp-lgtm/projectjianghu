เพิ่มเติมรอบนี้
1. ตีธรรมดาทั้ง4คลาสไม่มี skill cooldown อีกต่อไป ไม่ขึ้นเลข CD หรือทำให้ปุ่มมืดจากCD จบท่าแล้วเริ่มตีครั้งถัดไปได้ทันที เซิร์ฟเวอร์ยังห้ามโจมตีซ้อนระหว่างอนิเมชั่น
2. รับคำสั่งตีธรรมดาช่วงท้าย120msไว้ได้ครั้งเดียว ไม่สะสมคำสั่งเป็นสิบครั้ง กดค้างตีต่อได้ ปล่อยแล้วหยุดหลังท่าหรือคำสั่งที่รับไว้จบ CC/กดการ์ดล้างคำสั่งค้างได้ การย้ายwheelไม่ล้างCDสกิลอื่น
3. ค่าระยะเวลาท่าตีเดิมยังคงอยู่ (กระบี่0.46 ถัง0.50 ขลุ่ย0.60 หมอ0.55วินาที) ไม่มีการเพิ่มสูตร ASPD/AGI/ของสวมใส่ใหม่ในรอบนี้
4. ขลุ่ยเปลี่ยนภาพ FX6แถวเป็นคลื่นเสียงหยก/ขาวสะอาด ท่าเป่าปล่อยระลอกที่ค่อยแผ่กว้างและ crossfade ระหว่างเฟรม ลดความเป็นลูกดอก ปลายระยะยังค่อยสลาย
5. ขณะเป่ามีโน้ตเล็กๆขนาดที่เห็นจริงราว8–12หน่วยใกล้ปาก ลอยขึ้นช้าๆและเลือนหายในประมาณ1.6วินาที เป็นภาพตกแต่งเท่านั้น ไม่เป็นกระสุน ไม่เพิ่มดาเมจ ไม่มีฮิตบ็อกซ์ และไม่ได้ถูกส่งเป็นentityบนnetwork
6. กระบี่แหวกธาร(เจาะการ์ด)ตีรอบตัวทั้งหน้าและหลัง ระยะจาก140เป็น165หน่วย ยังคงSP12/CD7/ดาเมจเดิม ใช้วงวารีล้อมผู้ร่าย ไม่มีการย้ายศูนย์วงไปเป้าหมาย และยังตรวจพื้น/ผนังระหว่างชั้น
7. อาร์ตตัวละคร ขนาดตัว แผนที่ ฟิสิกส์ สูตรฮีล40%/60วินาที และสกิลอื่นคงเดิม
