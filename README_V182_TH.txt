- ดาวน์โหลดFE3พาร์ต + Backendเต็ม + MERGE_V182.ps1 วางโฟลเดอร์เดียวกัน
- PowerShell:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\MERGE_V182.ps1"
- สคริปต์ตรวจSHA256ทั้ง4ZIP แล้วแตกเป็นโฟลเดอร์ใหม่เสมอ ไม่คัดทับโฟลเดอร์เก่า
- อัปโหลดFrontend V182ทั้งโฟลเดอร์ขึ้นโฮสต์ และBackend V182ทั้งชุดเข้าrepo/checkoutที่ใช้จริง
- Backend V182จำเป็นสำหรับคอมโบและเอฟเฟกต์ออนไลน์ ไม่ใช่แค่อัปFrontend
- หลังอัปไฟล์Backendบนเซิร์ฟเวอร์แล้ว:
  cd /opt/jianghu
  git pull --ff-only
  bash RESTART_AND_VERIFY_V182.sh
  สคริปต์ค้นหาเฉพาะserviceเดิมที่WorkingDirectoryตรงกับโฟลเดอร์นี้และเรียกserver.py
  ถ้าพบไม่ใช่หนึ่งservice จะหยุดโดยไม่เปลี่ยนserviceใด ๆ ไม่แก้.env/config/สิทธิ์/ฐานข้อมูล
  ตรวจไฟล์ที่ติดตั้งแยกจากโปรเซสที่รันจริงด้วย /healthz ต้องระบุJIANGHU_BACKEND_V182
  ตรวจอย่างเดียว: .venv/bin/python VERIFY_RUNNING_V182.py
