WUXIA FLUTE ARENA v7.7 — GUEST ONLINE HOTFIX

Web (Netlify):
- แก้การมองเห็นมอนสเตอร์หลังเกิดใหม่: ซ่อนเมื่อ dead > 0 เท่านั้น และ normalize ค่า timer เก่าที่ติดลบ
- ลดต้นทุนการเรนเดอร์ขณะออนไลน์ด้วยการจำกัด DPI ที่ 1.5 (ออฟไลน์คงเดิมสูงสุด 2)
- ไม่วาดฉากเกมซ้ำขณะเปิดหน้าสร้างตัวละคร; cache สีพื้นหลัง
- คัดกรองมอนสเตอร์/ผู้เล่น/เอฟเฟกต์นอกหน้าจอเพื่อลดภาระการวาด
- ให้มอนและกระสุนเคลื่อนต่อเนื่องระหว่าง snapshot (ภาพเท่านั้น; ตำแหน่งและดาเมจจริงอยู่ที่เซิร์ฟเวอร์)
- แสดงตัวเลข FPS ในแถบสถานะออนไลน์เพื่อช่วยแยก render FPS กับ network stutter

Server (Render):
- รีเซ็ต dead timer เป็น 0 เมื่อมอนเกิดใหม่ (เดิมอาจเหลือ -0.03 ส่งไปที่ client)
- รีเซ็ต dead timer เป็น 0 เมื่อ Guest เกิดใหม่
- ไม่เปลี่ยนกติกากันโกง / การคำนวณดาเมจ / ระบบตำแหน่ง Authoritative
