FRONTEND

BACKEND
แตก JIANGHU_BACKEND_V156_FULL_FOR_FE170.zip ไปยังโฟลเดอร์ backend จะมี server.py, requirements.txt, world_v56.json และโมดูลครบที่ root
Python 3.11+; ติดตั้ง dependency ด้วย python3 -m pip install -r requirements.txt ใน virtualenv เดิม
คงค่า environment และ reverse proxy/TLS เดิม แล้ว restart service เดิม
ไม่รวม virtualenv, secret, ฐานข้อมูล หรือข้อมูลผู้เล่นที่อยู่บนเซิร์ฟเวอร์จริง
