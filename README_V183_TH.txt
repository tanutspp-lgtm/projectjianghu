รายการแก้ตามคำสั่งผู้ใช้5ข้อ:
1. เอาเอฟเฟกต์อาวุธ/คลื่นซ้ำที่หัวมอนสเตอร์เมื่อโดนดาเมจ ล้ม บล็อก หรือทลายการ์ดออกทุกอาชีพ
   คงเอฟเฟกต์ฟันที่ตัวผู้เล่น/กระสุนจริง, เลขดาเมจ, เสียงโดน, สถานะ และเอฟเฟกต์ปราณเดิม
2. Aim Assist อยู่ Settings ปิดเป็นค่าเริ่มต้น โจมตีตามหน้าที่หัน
   เปิดเพื่อช่วยหันเข้าหาเป้าตามระบบเดิม จำค่าในเบราเซอร์และส่งค่าที่เลือกให้เซิร์ฟเวอร์หลังเชื่อมต่อใหม่
   AUTO ยังเลือกและหันเข้าเป้าของตนเอง ไม่ผูกกับตัวเลือกช่วยเล็งของการเล่นมือ
3. ตีธรรมดาสกุลถังเลือกชนิดตอนเริ่มร่าย: มีเป้าด้านหน้าในกล่องฟัน102หน่วย => ฟัน; นอกระยะ => ปามีด
   ใช้ฟัน1–2สลับเดิม; ปาใช้แถวปาเดิม ไม่กินลำดับคอมโบฟัน และใช้ดาเมจ/คูลดาวน์ตีธรรมดา
   ปาธรรมดาไม่ยืมสถานะล้มของสกิลK; KปามีดและUทลายการ์ดคงเดิม
   เลือกจากมอนสเตอร์ฝั่งเซิร์ฟเวอร์ ไม่รับระยะ/เป้า/ดาเมจจากผู้เล่น
4. หมอ: คูลดาวน์ฮีล3วินาทีแยกจากเวลาพักการโจมตี ฮีลจบอนิเมชั่น.60วินาทีแล้วตีธรรมดาต่อได้
   ฮีล15% MaxHP/ใช้SP16/ระยะ300คงเดิม โจมตีระหว่างรอฮีลไม่เลื่อนเวลาฮีลครั้งถัดไป
   คงการตรวจเวลาเซิร์ฟเวอร์และเงื่อนไขขัดจังหวะ ป้องกันกดซ้ำก่อนจบร่าย
5. ฟันประชิดเด้งผิดด้าน: เดิมความเร็วกระสุนระยะใกล้เป็น0แล้ว fallback ไปใช้กลางกล่องฟัน
   ตอนมอนอยู่ชิดจึงผลักย้อนผ่านผู้เล่น แก้ให้ใช้ทิศฟันที่ล็อกไว้ตอนเริ่มโจมตี
   ออนไลน์ส่งทิศโดนตีเพื่อให้ท่า recoil แรกตรงกับการกระเด็นจริงด้วย

ติดตั้ง:
- Frontend3ZIPคือพาร์ตอิสระของตัวเต็ม ไม่ใช่ZIPแบ่งไบต์ ให้แตกทั้งหมดลงโฟลเดอร์ใหม่เดียวกัน
- วางFrontend3ZIPและMERGE_V183.ps1ไว้Downloadsแล้วรัน:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\MERGE_V183.ps1"
  สคริปต์ตรวจSHA256 แตกเป็นโฟลเดอร์ใหม่ และสร้างJIANGHU_FRONTEND_V183_FULL.zipให้ด้วย

  แตกทับcheckout Backend V182เดิม แล้วอัปไฟล์เหล่านี้เข้าrepoที่VPSใช้จริง
- หลังpushไฟล์BackendและอัปFrontendแล้ว ที่VPS:
