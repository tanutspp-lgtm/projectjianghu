Seven Wind V239 — ชุดเกมจริง

ต่อจาก frontend/backend V235 ตัวเต็ม เพิ่มงานแมพที่อนุมัติล่าสุด
- ใช้ภาพชุดผาท้อ 7 แมพล่าสุดแทนชุดป่าท้อ–ผาเงาจันทร์เดิม ใช้ map ID เดิมเพื่อคงการอ้างอิง
- เปิดจากเมนูเปลี่ยนแผนที่ เลือกชื่อขึ้นต้น ผาท้อ; ทั้ง 7 แมพต่อกันด้วยทางออกซ้าย/ขวา ใช้ปุ่มขึ้นที่จุดวาร์ป
- จุดเริ่มตัวละครใหม่ยังเป็นปากป่าไผ่แรกอรุณ (BAM_START_01) หน่อเซียนทั้ง 4 แมพยังอยู่
- เชือกป่าไผ่แมพ 1 และ 3 อีดิทภาพให้เล็กลง ปลายพ้นพื้น; กระโดดพร้อมกดขึ้นเพื่อจับเชือก
- พิกัดเส้นชน/เชือก frontend และ backend ตรงกัน ไม่เปลี่ยนฟิสิกส์รวม
- เก็บข้อมูลแมพเดิมใน archived_maps/peach_before_v239.json ฝั่ง backend; ภาพเก่ายังคงอยู่
- คงการแก้โหลดแมพค้าง 0% และแสดงความคืบหน้ารายเลเยอร์; ใช้ภาพหมอก/แสงร่วมกันเพื่อลดการโหลดซ้ำ

Frontend: ดาวน์โหลดครบสามส่วนไว้โฟลเดอร์เดียว เปิด PowerShell ในโฟลเดอร์นั้น แล้วรัน
cmd /c copy /b "SevenWind_Frontend_V239_FULL.zip.001+SevenWind_Frontend_V239_FULL.zip.002+SevenWind_Frontend_V239_FULL.zip.003" "SevenWind_Frontend_V239_FULL.zip"
จากนั้นแตก ZIP ที่รวมได้และอัปโหลดไฟล์ตัวเต็มขึ้น Vercel เหมือนเดิม index.html เป็นหน้าเข้าเกมจริง

Backend: SevenWind_Backend_V239_FROM_V219.zip เป็นแพตช์สะสม เทียบเนื้อหาไฟล์กับ V219 FULL
แตก ZIP แล้วนำไฟล์และโฟลเดอร์ไปอัปโหลดใน backend repository เดิมและ Commit ก่อน
ZIP นี้ไม่ได้ push ไป GitHub หรือเปลี่ยนเซิร์ฟเวอร์ให้โดยอัตโนมัติ
จากนั้นบน Hostatom รันทีละบรรทัด:

bash RESTART_AND_VERIFY_V239.sh

ติดตั้ง backend ก่อน frontend เพื่อให้เซิร์ฟเวอร์รองรับพิกัดใหม่
ผู้ใช้ที่ติดตั้งบันทึก EXP/เมลแล้วไม่ต้องรัน SQL หรือตั้งคีย์ซ้ำ แพตช์ไม่รวม/ไม่ทับข้อมูลผู้เล่น คีย์ หรือไฟล์ .env
ถ้ายังอยู่ V219 ล้วนและไม่เคยติดตั้งระบบบัญชี/EXP ให้ทำตาม ACTIVATE_ACCOUNTS_TH.md ก่อนใช้งานระบบดังกล่าว

ผลตรวจในสภาพแวดล้อมทดสอบ:
- ฟิสิกส์ frontend: เส้นทางกระโดดและปีนทั้ง 7 แมพผ่าน; ทางล่าง 14 เที่ยวไปกลับ, เชือก 7 จุด, ปลายหน้าผาตกแล้วคืนจุดเกิดผ่าน
- ฟิสิกส์ server: เส้นทางทั้ง 7 และวาร์ปไปข้างหน้า 6 จุดผ่าน
- ป่าไผ่ 4 แมพ: เดินไปกลับและขึ้นพื้นชั้นบนผ่าน; เชือกใหม่ 2 จุดขึ้นลงผ่านทั้ง frontend/server
- โหลดต่อเนื่อง 1–7 และย้อนกลับผ่านใน regression จำลองโหลดภาพ โดยให้แมพเดิมวาดต่อระหว่างรอ
- ตรวจทุกภาพที่ scene อ้างอิงและขนาดภาพ; พิกัดทั้ง 9 แมพที่เปลี่ยนตรงกัน
